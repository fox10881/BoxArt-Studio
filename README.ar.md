**حوّل مجلدات Windows واختصارات الألعاب المملّة إلى رفّ ألعاب أنيق يبدو وكأنه ماديّ.**

BoxArt Studio أداة Windows خفيفة وحديثة تفحص تلقائيًا اختصارات ألعابك ومجلداتك، وتطابقها مع أغلفة عالية الجودة من SteamGridDB، وتطبّق قوالب تجميلية قابلة للتخصيص لتجعلها تبدو كعلب ألعاب مادية حقيقية.

## ✨ الميزات الرئيسية

* **🤖 المطابقة التلقائية الذكية:** مدعومة بواجهة SteamGridDB API، يقرأ التطبيق تلقائيًا أسماء اختصاراتك ومجلداتك ويجلب أفضل أغلفة بأبعاد 2:3.
* **📦 قوالب علب مادية:** اجعل مجموعتك الرقمية تبدو ملموسة. طبّق ملصقات شفافة أسفل الأغلفة، تشمل:
  * شعارات المنصات: `PC CD-ROM`، `DVD`
  * تصنيفات الأعمار: `ESRB (T)`، `PEGI 18` (تُرتَّب بذكاء لمنع التداخل)
  * أختام الجودة
* **🎨 محرك عرض متقدم:** مبنيّ على Win2D. يعالج التطبيق ملاءمة الأبعاد بدقة دون تمدد أو ضغط غير متناسق، مع الحفاظ على العمل الفني الأصلي وإضافة خلفيات شفافة لمظهر أنيق على سطح المكتب.
* **🔄 دعم كامل للتراجع:** لا يعجبك الغلاف؟ ميزة «إزالة الأيقونة المخصصة» تحذف ملف `desktop.ini` فورًا أو تعيد تعيين ملف `.lnk` لاستعادة المظهر الافتراضي لنظام Windows.
* **🌍 ثنائي اللغة وجاهز للاتجاه من اليمين إلى اليسار:** واجهة WinUI 3 مصممة بعناية مع دعم كامل للإنجليزية والعربية (قلب التخطيط بالكامل ليتوافق مع اتجاه RTL).
* **🐛 وحدة تحكم مدمجة للتصحيح:** عارض سجلات مباشر داخل التطبيق يتيح لك مراقبة طلبات API ومشكلات أذونات الملفات وخطوات المعالجة دون الحاجة إلى تتبّع ملفات نصية مخفية.
* **⚡ مثبّت خفيف:** بنية تعتمد على المكتبات المشتركة (framework-dependent) تُبقي حجم المثبّت صغيرًا للغاية (~20 ميجابايت) مع جلب حزم .NET 8 وWindows App SDK المطلوبة تلقائيًا عند الحاجة.

## 🚀 طريقة الاستخدام

1. احصل على مفتاح API مجاني من [SteamGridDB](https://www.steamgriddb.com/profile/preferences/api).
2. افتح **BoxArt Studio** والصق المفتاح.
3. اختر مجلد ألعابك.
4. دع التطبيق يفحص ألعابك، أو اختر أغلفة بديلة يدويًا من واجهة الاستوديو المدمجة.
5. فعّل الملصقات التي تفضّلها واضغط **تطبيق**!

6. ### ⚠️ متطلبات النظام
هذا إصدار خفيف يعتمد على المكتبات المشتركة. لتشغيل التطبيق، يُرجى التأكد من تثبيت حزم Microsoft الرسمية التالية على جهازك:
1. [.NET 8.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
2. [Windows App SDK 1.8 Runtime (x64)](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads)

## 🛠️ التقنيات المستخدمة

* **الإطار:** WinUI 3 / Windows App SDK (C#)
* **الرسوميات:** Win2D لتركيب الصور ومزج الشفافية (alpha-blending) بتسارع العتاد.
* **التوزيع:** Inno Setup لعملية تثبيت مؤتمتة بالكامل وسهلة الاستخدام.
